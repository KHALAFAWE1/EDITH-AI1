## 2. Real Data Source Architecture

Each dynamic subsystem must map to a verified operating system or sensor source:

* **Host Telemetry**: `psutil.cpu_percent()`, `psutil.virtual_memory()`, `psutil.disk_usage()`, `psutil.sensors_battery()`.
* **Task Manager / Processes**: `psutil.process_iter(['pid', 'name', 'cpu_percent', 'memory_percent', 'username', 'status', 'create_time'])`.
* **Network & CyberVision**: OS network interfaces via `psutil.net_if_addrs()`, active sockets via `psutil.net_connections()`, ARP cache inspection.
* **Camera Manager**: Browser `navigator.mediaDevices.enumerateDevices()` + OpenCV backend device probing (`cv2.VideoCapture`).
* **Smart Glasses Pairing**: Dynamic cryptographically random UUID pairing tokens with 5-minute TTL stored in SQLite/PostgreSQL `PairingSession`.
* **Episodic Memory & Events**: Real immutable database records generated by user logins, camera triggers, biometric face matches, and system alerts.
* **AI Responses**: Real Google Gemini Vision / Text API responses or local Ollama instances (with clean abstraction hiding raw metadata).

## 3. Mandatory Offline / Empty State Standards

When a subsystem is disconnected, unreachable, or unpermitted:
* **Camera**: `"Not Connected"` / `"Camera Offline"` / `"Permission Required"`
* **Network Nodes**: `"No Authorized Nodes Detected"`
* **Events**: `"No Events Recorded in Timeline"`
* **Process Manager**: `"Permission Required"` / `"Access Denied"`
* **AI Engine**: `"AI Service Unavailable"`
* **Smart Glasses**: `"No Paired Glasses Client"`
